# SIGECAM

## Sistema Integral de Gestión de Capacitaciones y Certificaciones de Mantenimiento

### Descripción
SIGECAM es una plataforma web enfocada en administrar y dar seguimiento a las capacitaciones y certificaciones del personal de mantenimiento.

### Objetivo
Centralizar la información del personal técnico, cursos, evaluaciones y certificaciones para mejorar la organización y el seguimiento de las actividades de capacitación.

### Funcionalidades principales
- Registro y administración de técnicos.
- Gestión de cursos y capacitaciones.
- Registro de asistencias y evaluaciones.
- Consulta del historial de capacitación.
- Control de vigencias y certificaciones.
- Generación de reportes.
- Seguimiento de recertificaciones.

### Estado del proyecto
Primera versión - Proyecto académico.
